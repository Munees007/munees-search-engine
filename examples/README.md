# Small HTML, Tailwind CSS, and JavaScript projects

Each project is self-contained. Open its `index.html` in a browser to try it.
Tailwind CSS is loaded from its CDN, so an internet connection is needed for styling.

- `semantic-seo/` demonstrates semantic HTML, useful page metadata, accessible navigation, and a well-structured article.
- `beginner-counter/` demonstrates basic JavaScript variables, event listeners, and DOM updates in a small counter app.
